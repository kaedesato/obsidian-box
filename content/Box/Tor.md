The Onion Routerの略
３つのサーバーを自動的に経由して匿名化してくれるシステム。
層を作ってるイメージでOnion。


### つかいかた
Tor Browser か BraveのTorモードを使うとできる。基本はBraveでいいかなと思う。
どちらにせよ設定はデフォルトで安全になっている。
- Braveだと出口ノード設定できない？

もしやばい国にいるのであればブリッジを有効化すればOK。

### リレーの種類

> Tor ユーザー -> ガードリレー -> 中間リレー -> 出口リレー -> 宛先 

> ブリッジを使用する場合:
> Tor ユーザー -> ブリッジリレー -> 中間リレー -> 出口リレー -> 宛先 

[Tor Project \| Tor ネットワークにおけるリレーの種類](https://community.torproject.org/ja/relay/types-of-relays/)
