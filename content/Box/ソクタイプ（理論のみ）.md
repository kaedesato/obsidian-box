### 親指の役割
- 二音目ショートカット
- 略語キー
- 助詞

**二音目ショートカット**
片手の単押し、もしくは両手のそれぞれ単押しで二音目のショートカットをすることができる。

|     |     |
| --- | --- |
| t   | つ   |
| k   | く   |
| i   | い   |
| n   | ん   |
| ti  | ち   |
| ki  | き   |
| tn  | っ   |


**略語**
親指同時押しで略語モードになる。
頭文字＋親指同時押しで略語が出力される。

**助詞**
親指だけ押すと助詞が出る。
```
      T            に  
       K           が  
         I         は  
          N        の  
      T  I         には  
      T   N        にの  
      T  IN        にも  
      TK I         では  
      TK  N        での  
      TK IN        でも
```
