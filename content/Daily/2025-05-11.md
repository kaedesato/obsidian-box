今の状況

あるディスクのすべてのパーティションを消そうとしたところ、
OS（ubuntu）のパーティションをすべて消してしまった。（Fdisk）

Fdisk書き込み（削除する）時に再起動しろと言われたので、
再起動したところ、Grub resqueが表示されたので、なんかミスった事に気づいて、
色々やってたら、パーティションを誤って消していたことが判明。

まずはTestdiskでパーティションを再生させようと思いました。
ここでとりあえず、表示されてた全部のパーティションを再生させました。
具体的には、３つあって、上２つは100MBくらいのパーティションで、
一番下のパーティションにhomeなどのUnixのディレクトリが入っています。
ちなみに/bootも一番下のパーティションに入ってます。

でこれで治ったと思いきや、
なんかうまく起動できず、Gnu Grubという画面が表示されてしまいます。

やったこととしては、
```sh
sudo mount /dev/nvme0n1p3 /mnt
sudo mount /dev/nvme0n1p1 /mnt/boot/efi
sudo mount --bind /dev /mnt/dev
sudo mount --bind /sys /mnt/sys
sudo mount --bind /proc /mnt/proc
sudo mount --bind /dev/pts /mnt/dev/pts
sudo chroot /mnt

sudo apt update
sudo apt install --reinstall grub-efi-amd64-signed
sudo update-grub
sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ubuntu

```
というのをやりましたが、
sudo mount --bind /dev/pts /mnt/dev/pts
と
sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ubuntu
でエラーが発生しうまくいきませんでした。

助けて！
